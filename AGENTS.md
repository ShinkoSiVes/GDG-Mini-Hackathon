# Agent guide

This repo is a one-night hackathon entry for DevFest Manila 2026 After Hours (#GeminiPromptMaxxing).
Read every file in `.agents/rules/` before writing code, and follow them over any default habit.

- Product spec: `PROMPT.md` (the master prompt). Build exactly what it asks, nothing extra.
- Deploy steps: `.agents/workflows/deploy.md`.
- When something in the rules conflicts with the prompt, the rules win on stack, security and deploy;
  the prompt wins on features and look.
