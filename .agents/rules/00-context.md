# Context

- One-night solo hackathon. The judged items are: the prompt itself, what you build from it, a short
  screen recording of the build, and a public deployed link. Optimise for a working, impressive demo
  tonight, not for long-term architecture.
- The demo must show its "wow" moment within 10 seconds of opening the deployed URL.
- Gemini must be central to the app, not decoration: the core feature should not work without it.
- Scope rule: ship one complete flow end to end before adding anything else. If a feature risks the
  deploy, cut it and say so.
- Never invent data and present it as real. Seed or sample data must be labelled as sample data.
