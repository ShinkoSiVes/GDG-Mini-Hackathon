# UI and quality

- Mobile-first and responsive: it must look right at 390px wide and on a laptop. No horizontal scroll.
- Distinctive, intentional look. No generic gradient-hero template, no lorem ipsum, no stock placeholder
  icons standing in for content. Pick one clear visual direction and apply it consistently.
- Every async action shows loading, success, empty and error states.
- Streaming or progressive output from Gemini when it improves the feel of the demo.
- Accessible basics: semantic HTML, labels on inputs, visible focus, sufficient contrast.
- Include a short "How it works / Powered by Gemini on Google Cloud" note in the footer.
- Before saying a feature is done: run the build, start the app, and exercise the main flow once.
- Keep a short `README.md`: what it does, how to run locally, how it is deployed, the live URL.
